# 数据来源映射 — UI 组件 ↔ HMBU安全漏洞管理表.xlsx

> 数据文件：`data.js`（ESM 导出 `VULN_DATA`）
> 页面：`index.html`（根素材 `App.jsx`）、`detail.html`（根素材 `detail.jsx`）

## 素材拆分一览

| 素材 | 作用 | 对应原 HTML 区块 |
| --- | --- | --- |
| `App.jsx` | 页面1 根素材：Tab / 分页状态 + 数据切片 + Toast | `index.html` 主体 |
| `detail.jsx` | 页面2 根素材：详情页数据装配 | `detail.html` 主体 |
| `Components/SiteHeader.jsx` | 白色主导航 | `.main-header` |
| `Components/Breadcrumb.jsx` | 面包屑 | `.crumb-bar` |
| `Components/TabBar.jsx` | 安全通告 / 安全公告 双 Tab | `.tab-bar` |
| `Components/VulnTable.jsx` | 斑马纹列表（SA 6 列 / SN 3 列） | `.vul-table` |
| `Components/SeverityText.jsx` | 漏洞等级文本 + 等级映射 | `.sev-text` |
| `Components/Pager.jsx` | 共 N 条 + 页码 + 跳页 | `.pager` |
| `Components/EntryCards.jsx` | 漏洞上报 / 漏洞处理流程入口卡片 | `.entry-cards` |
| `Components/SiteFooter.jsx` | 页脚 | `.site-footer` |
| `Components/Toast.jsx` | 占位入口轻提示 | `#toast` |
| `Components/BackLink.jsx` | 返回上一页 | `.back-link` |
| `Components/SeverityChip.jsx` | 详情页漏洞等级徽章 | `.sev-chip` |
| `Components/MetaGrid.jsx` | 详情页元信息行 | `.meta-grid` |
| `Components/DetailSection.jsx` | 详情页章节容器 | `.detail-section` |

## index.html（安全通知列表页）

| UI 组件（类选择器） | 显示内容 | xlsx 数据源 |
| --- | --- | --- |
| `.vt-head.sa` / `.vt-row.sa` | 安全通告表格（6列容器） | 安全通告 子表 |
| `.row-desc` | 漏洞描述（链接→detail.html） | 安全通告.`漏洞描述` |
| `.col-mono`（第2列） | 内部编号 | 安全通告.`内部编号` |
| `.col-mono`（第3列） | 漏洞编号 | 安全通告.`漏洞编号` |
| 第4列（无专用类） | CVSS3评分 | 安全通告.`CVSS3评分` |
| `.sev-text` + `.sev-high` / `.sev-medium` / `.sev-low` | 漏洞等级 | 安全通告.`漏洞等级` |
| `.col-date`（SA 第6列） | 发布时间（空值显示 `-`） | 安全通告.`发布时间` |
| `.vt-head.sn` / `.vt-row.sn` | 安全公告表格（3列容器） | 安全公告 子表 |
| `.row-title` | 漏洞标题（链接） | 安全公告.`漏洞标题` |
| `.col-mono`（SN 第2列） | 内部标识 | 安全公告.`内部标识` |
| `.col-date`（SN 第3列） | 发布时间 | 安全公告.`发布时间` |
